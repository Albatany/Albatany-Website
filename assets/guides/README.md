# Guides

Taruh file PDF guide book di folder ini, lalu tambah satu entri di `assets/js/content.js` bagian `GUIDES` (isi `"pdf": "assets/guides/nama-file.pdf"`). Sampul opsional: simpan gambarnya di sini dan isi `"cover"`.

Put guide book PDFs in this folder, then add one entry to the `GUIDES` section of `assets/js/content.js`. Cover images are optional.
